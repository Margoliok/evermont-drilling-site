# EVERMONT Drilling & Geoservices — дизайн-макет сайта

Кликабельный макет корпоративного B2B-сайта дочерней компании группы Evermont Mining Group
(геология · геофизика · бурение · поставка бурового оборудования). Составлен по ТЗ.

- `index.html` — главная (все блоки ТЗ: направления, оборудование, проекты, преимущества, о компании, сертификаты, новости, форма заявки, контакты)
- `drilling.html` — страница «Буровые услуги»
- `rig.html` — карточка буровой установки + каталог с фильтрами

Статический HTML/CSS/JS, без сборки. Название компании, цифры и ТТХ — плейсхолдеры для согласования.
